# 05 · Boss question pools

Status: ready-for-agent
Blocked by: 03
Spec: [../spec.md](../spec.md) (Bosses: scope per boss)

## What

Write about 20 scenario questions per boss (Fundamentals, AI Agent, Nexus) in `pool.yaml`. Each question has a scenario (a snippet, a history slice or a timeline), the answer, a 1–2 sentence explanation, and the module that teaches it. No recall-only questions and no free text. Questions only cover the boss's own branch and that branch's prerequisites.

Draft with an agent, then have a human review for accuracy (Temporal semantics, Monty and Dogwood behaviour).

## Done when

Each pool has ≥ 20 questions covering every scope item listed in the spec, every question links to an existing module, and Tao has reviewed all three pools.
